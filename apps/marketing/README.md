# Explorin marketing site

The public landing page. Static HTML and CSS with no build dependencies; see [ADR-0002](../../docs/adr/0002-marketing-site-static.md) for why.

```bash
npm run dev -w apps/marketing     # syncs brand assets, serves public/ on http://localhost:4321
npm run build -w apps/marketing   # syncs brand assets; deploy the public/ folder
```

- `public/index.html`, `public/styles.css`: the page. The app link is the `APP_URL` constant at the top of the script in `index.html`.
- `public/brand/`: generated by `sync-brand` from [`packages/brand`](../../packages/brand/) and gitignored. Add files to the script when the page needs more of the kit.
- `public/images/`: the three web-optimised postcards the page uses.
- `assets/images/`: source photography for marketing use (originals, not served). Web-optimised copies also live in `../web/static/marketing/`.
