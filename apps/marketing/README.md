# Explorin marketing site

The public landing page and waitlist. SvelteKit on Cloudflare Workers, waitlist rows in D1. See [ADR-0006](../../docs/adr/0006-marketing-on-workers-with-waitlist.md).

## Run it

```bash
npm run dev -w apps/marketing      # syncs brand assets, applies the migration to a local D1, serves http://localhost:4321
npm run check -w apps/marketing    # svelte-check with generated Worker types
npm run preview -w apps/marketing  # production build under wrangler dev
```

Copy `.env.example` to `.env` first: the waitlist only accepts a submission after a passed Cloudflare Turnstile challenge verified server-side, so it needs the Turnstile keys (Cloudflare's always-pass test pair works for local dev). The dev server uses a local D1 emulated by wrangler, so the form works offline. Rows land in `.wrangler/state/`.

## First deploy

```bash
cd apps/marketing
npx wrangler d1 create explorin-waitlist      # paste the database_id into wrangler.jsonc
npm run db:migrate                            # creates the waitlist table in the remote D1
npm run deploy
```

Then the secrets, once each:

```bash
npx wrangler secret put TURNSTILE_SECRET_KEY
npx wrangler secret put RESEND_API_KEY          # optional: welcome email
```

Non-secret settings (`TURNSTILE_SITE_KEY`, `TURNSTILE_HOSTNAMES`, `APP_URL`, `WAITLIST_FROM_EMAIL`) go in `wrangler.jsonc` under `vars`; defaults and descriptions live in `src/env.ts`. Export the list with `npm run waitlist:export`.

## Layout

- `src/routes/+page.svelte`: the page. `+page.server.ts` holds the `join` form action: honeypot, zod email check, Turnstile siteverify (action `waitlist`, hostname allowlist), insert-or-ignore, welcome email.
- `src/lib/Turnstile.svelte`: the widget, rendered explicitly; the submit button stays disabled until it passes, and it resets after every attempt because tokens are single-use.
- `src/lib/server/turnstile.ts`: siteverify, fails closed. `src/lib/server/email.ts`: Resend welcome email, optional.
- `src/lib/server/waitlist.ts`: D1 queries. `migrations/`: schema, applied by `wrangler d1 migrations`.
- `src/env.ts`: every environment variable, with defaults and descriptions.
- `src/app.css`: styles, palette from [`packages/brand`](../../packages/brand/).
- `static/brand/`: generated by `sync-brand` from the brand package and gitignored. `static/images/`: the three postcards.
- `assets/images/`: source photography (originals, not served).
