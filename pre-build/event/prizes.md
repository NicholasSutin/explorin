## Best Use of Tiger Data

- Prize: Stream Deck Mini
- Tiger Data extends PostgreSQL for real-time data, time-series metrics, and complex analytics. Why build with Tiger Data:
  - Standard SQL Power: query massive datasets instantly using the SQL you already know, no NoSQL aggregation pipelines required
  - Unified Data Stack: store relational user profiles and high-frequency metric streams side-by-side in a single database
  - Instant Dashboards: serve lag-free, real-time frontend charts using pre-computed Continuous Aggregates
  - 90%+ Data Compression: store millions of events on free-tier cloud instances without running out of disk space
- Example ideas: real-time IoT monitoring, AI-driven analytics dashboards, financial prediction engines
- Winner: team that demonstrates the most innovative, impactful, and performance-driven use of Tiger Data
- Get started: https://mlh.link/tigerdata

## Best Use of Sentry (and Raffle)

- Prize: mechanical keyboards for one standout winning team
- Raffle: anyone who uses Sentry is also entered into a raffle for mechanical keyboards
- Opt-in required: you must opt in to the Sentry prize category when you submit your project
- Sentry shows what went wrong (errors, slow requests, what your agent actually did) so you can fix it before demo time. Ways to use Sentry:
  - Sentry MCP Server: connect Sentry to your coding agent so it pulls issues, stack traces, and root-cause context into your editor
  - AI Agent Monitoring: trace your agent's LLM calls, tool calls, and token usage to see where it slows down or goes off the rails
  - Error Monitoring and Tracing: drop in the SDK and catch crashes and performance bottlenecks across frontend and backend
  - Seer: Sentry's AI debugger finds the root cause of an issue and suggests a fix
- Get started: sign up for Sentry's free 14-day trial (no credit card required) and see the Sentry Cookbook for quick recipes (no URLs given on the MLH page)
